This folder contains selected generated output from **Lab 14: AI Alert Explainer v2 Multiple Alert Processing**.

The published files are representative examples from the validated Lab 14 workflow. They demonstrate batch-level processing results and safe handling of incomplete or malformed alert data.

Only selected outputs are published here. The complete local validation workspace contains additional generated reports from repeated test runs.
